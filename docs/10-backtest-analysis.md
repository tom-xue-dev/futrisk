> 题目要求"通过历史数据回放验证风控规则的有效性"。本文说明回测怎么做、数据从哪里来、结果是什么，以及这些结果能说明什么、不能说明什么。先给结论：验收场景在生产的风控内核上被精确复现；日亏熔断规则在回测中的收益主要来自**拦住逆势加仓**，对不加仓的持仓几乎没有作用；它的效果大小依赖于日内路径的合成方式，是**以路径模型为条件**的结论；3% 是题目给定的阈值，不是回测优化出来的，阈值扫描也不支持"3% 落在平台区"的说法。

## 1. 要回答的问题

1. 按 04 定义的日亏规则（−2% 告警、−2.5% 限制下单、−3% 熔断禁开、−5% 生成减仓计划）在历史行情上会不会触发、触发得对不对（真阳 / 假阳）；
2. 触发之后，禁止开仓、减半、清仓这几档动作分别带来多少收益或损失，对哪类账户有用；
3. 3% 这个阈值放在参数空间的什么位置：是否稳健、是否过紧或过松；
4. 验收场景（ACC3 的 −3% 熔断）在回放中能否被精确复现。

## 2. 方法

### 2.1 同一个风控内核
回测不启动任何服务：同一个 `EngineCore` 加进程内总线 `InprocBus`、进程内券商和同一个 `settle_day`（01 §8.16）。因此回测里的告警状态机、事前检查、熔断确认与锁存、逐日盯市结算，与生产代码完全相同；与生产不同的只有数据来源（历史数据代替行情网关）和成交方式（按价格点成交，无滑点、无部分成交）。

### 2.2 配对实验
每个方案（arm）用相同的数据、相同的策略和种子回放，只有规则不同，所以两个方案的差值只来自规则本身。

| 方案 | 规则 | 用途 |
|---|---|---|
| `no_rules` | 不启用日亏规则 | 基线 |
| `alert_only` | 日亏规则的各级别都只告警 | 交易与 `no_rules` 完全相同（每次运行都校验）；用来统计真阳 / 假阳 |
| `block_open` | **生产规则**：−2.5% 限制下单（单笔减半、亏损品种禁止加仓）+ −3% 熔断（禁止开仓，允许平仓） | 题目要求的"熔断禁开" |
| `halt_only` | 只保留熔断，限制级别改为告警 | `block_open − halt_only` = 限制级别的贡献 |
| `halve` / `flatten` | `block_open` 加上熔断锁存时平掉 50% / 100% 持仓（用生产的减仓规划器下单） | 比较更激进的动作；生产环境只生成减仓计划，由人确认（TD-08） |
| `placebo_halt` / `placebo_flatten` | 不启用规则；在没有触发的随机交易日、相同的日内时点施加同样的动作，次数与真实触发相同 | 检验触发的"时机"是否有价值 |

阈值 T 整体缩放日亏阶梯：告警、限制、熔断、减仓分别是 T 的 2/3、5/6、1、5/3，T = 3% 时即 −2%、−2.5%、−3%、−5%。只启用日亏这一条规则，其他生产规则（回撤、集中度等）不参与，以便单独度量它。

### 2.3 账户与策略
五个演示账户（01 §7.1）的策略在 K 线上实现，与 strategy-sim 机器人的逻辑对应；另加一个对照账户：

| 账户 | 策略 | 初始资金 |
|---|---|---|
| ACC1 | 黑色系通道突破 | 1000 万 |
| ACC2 | 多品种趋势 | 2000 万 |
| ACC3 | 日内逆势加仓（亏损时按阶梯加仓），验收场景的主角 | 1000 万 |
| ACC4 | 股指方向 | 1000 万 |
| ACC5 | rb 跨期套利 | 500 万 |
| ACC3B | ACC3 的策略去掉加仓（`max_adds: 0`），对照组，不计入合计 | 1000 万 |

仓位按初始资金定规模，不复利：某个方案干预之后，下一次调仓时各方案又回到相同的目标持仓，配对差值只反映规则本身。收益和回撤都按初始资金计算。"TOTAL"是五个账户的合计，"STATIC"是除 ACC3 以外、不在日内加仓的账户合计。

### 2.4 日内路径
A 层只有日线（开、高、低、收），而熔断发生在盘中，日内路径必须合成。合成方式会影响结果，所以回测同时用两类路径：

- **确定性路径**：开盘价靠近哪个极值就先走哪个（`open_near_extreme`），另有"先高后低""先低后高"两种强制顺序做敏感性分析。各合约在同一时刻到达极值，是同步的、偏悲观的模型。
- **随机路径集合**（主要结果）：K 条路径，每条路径中每个合约日的极值先后按概率抽取，极值的时刻取自分钟线的经验分布，锚点之间是直线加布朗桥振荡，同一板块的品种通过高斯 copula 相关。这些参数都在 B 层分钟线上校准，再外推到 2015 年以来的全部交易日。开、高、低、收与日线完全一致。

另外，对每个账户日还做**界定分类**：对开盘后的持仓，计算任何与日线一致的路径所能达到的最坏和最好的当日最低盈亏，据此把每个级别的触发分为"必然触发""不可能触发""不确定"，给出真实触发次数的区间。

### 2.5 统计
- **主要指标**：总收益、最大回撤、Calmar、CVaR95 的配对差值（方案 − 基线）。随机路径集合报告各路径的中位数、5%~95% 路径区间，以及"路径 × 交易日块"自助法（20 日块）的 95% 区间；"显著"指按账户做 Holm 多重比较校正后自助 p 值 < 0.05。
- **拆分与对照**：限制级别的贡献（`block_open − halt_only`）；安慰剂的"时机价值"（真实 − 安慰剂）；加仓阶梯的贡献（ACC3 − ACC3B）。
- **真阳 / 假阳**：`alert_only` 的每次熔断触发，按收盘价、结算价、次日开盘价三种计价口径，看亏损是否持续到当日收盘或之后（以收盘口径为主：结算价是全天成交量加权价，下跌日高于收盘价，会低估亏损的持续性）。
- **确定性**：每次运行的 `manifest.json` 记录配置哈希、数据哈希（与 `data/hist/manifest.json` 逐文件核对）、种子、代码哈希；同一配置重跑，结果和风险事件哈希完全相同。

## 3. 数据

| 层 | 内容 | 来源与处理 | 用途 |
|---|---|---|---|
| A | 12 个品种（rb、hc、cu、au、i、j、m、IF、IH、IC、IM、T）的日线，2015-01-05 ~ 2026-09-24，共 2852 个交易日（IH、IC 从 2015-04-16，T 从 2015-03-20，IM 从 2022-07-22） | SHFE、CFFEX 用交易所的逐合约真实结算价，按前一日持仓量最大选主力、不回到更早的交割月；DCE 官方接口不可用，用新浪的逐合约数据，约 7% 的交易日没有结算价，用（最高 + 最低）/ 2 估算 | 主要结果、压力窗口、阈值扫描 |
| B | 新浪 60 / 15 / 5 分钟线，每个周期最多 1023 根：60 分钟线从 2025-09（股指）~ 2026-04（黄金）起，除 cu、au 外的 10 个品种的共同区间为 2026-01-13 ~ 2026-09-24；15 分钟线从 2026-06 ~ 2026-08 起；5 分钟线从 2026-08 ~ 2026-09 起 | 分钟线的成交量不可靠，结算仍用当日官方结算价，分钟线只决定日内路径 | 校准日内路径模型；与 A 层同窗口对照（`minute` 配置） |
| C | 自录 tick | 真实行情从 2026-09-28 开始录制，本文不含 | — |
| D | 合成剧本，正确结果已知 | `config/backtest/breaker_synthetic.yaml` | 验收场景的精确复现 |

数据由 `scripts/fetch_hist.py` 在开发期抓取，随仓库提交在 `data/hist/`（62 个 Parquet 文件，7.3 MB），出处和逐文件 SHA-256 见 `data/hist/SOURCES.md` 和 `manifest.json`；回测不访问网络。

**换月**：回测持有真实合约，换月日在开盘时平旧主力、开新主力，旧合约按它自己的昨结算计盈亏，所以当日盈亏中没有换月跳空；策略信号用按换月比例（新合约昨结算 ÷ 旧合约昨结算）回调的连续序列。DCE 没有新合约的官方昨结算，用估算值。

**与历史不一致的简化**（报告第 14 节有完整清单）：
- 合约乘数、最小变动价位、手续费、保证金率和交易时段一律用 2026 年的 `products.yaml`；
- 新委托在当前价格点全部成交，没有滑点和部分成交；
- 封板按启发式判断（当日极值达到涨跌停，或 ≥3.5% 的开盘 / 收盘极值），封板方向不成交；
- 合成路径在夜盘与日盘之间没有跳空，所以"开盘跳空触发"的占比是下限。

读法：
- 生产规则让合计收益提高 6.28 个百分点、最大回撤降低 2.21 个百分点，在这个模型下统计显著；
- 但效果**全部来自 ACC3**：不在日内加仓的四个账户合计为 0，去掉加仓的 ACC3B 只有 +0.19pp 且不显著。禁开只挡住新增的风险，不减少已有的持仓；
- 熔断后减半、清仓的效果更大，对不加仓的 ACC3B 也有正效果（+12.6pp、+26.1pp，校正后不显著），因为它们真正减少了持仓。但这两档动作对日内路径最敏感（§4.4），生产环境只生成减仓计划、由人确认（TD-08）。

### 4.3 效果来自哪里

**限制与熔断的拆分**：限制+熔断 = 仅熔断 + 限制级别。ACC3：+34.54pp = +29.50pp + 4.80pp；合计：+6.28pp = +5.36pp + 0.87pp。限制级别（单笔减半、亏损品种禁止加仓）约占 14%，其余来自熔断。

**加仓阶梯**：基线中 ACC3 比去掉加仓的 ACC3B 少赚 97.47 个百分点，即在合成路径上，逆势加仓本身是大幅亏损的。生产规则对 ACC3 的效果（+34.54pp）减去对 ACC3B 的效果（+0.19pp），得到 +34.35pp，占 ACC3 效果的 99%：规则的价值几乎全部在于**拦下了加仓**。

**安慰剂（触发时机是否有价值）**：把同样的动作放到没有触发的随机交易日（次数和日内时点与真实触发相同）：

| 动作 | 账户 | 安慰剂 | 真实触发 | 时机价值（真实 − 安慰剂） |
|---|---|---:|---:|---|
| 熔断（禁开到收盘） | ACC3 | +1.23pp | +29.50pp | +27.75pp [+22.16, +32.27] |
| | TOTAL | +0.22pp | +5.36pp | +5.05pp [+4.03, +5.88] |
| 熔断 + 清仓 | ACC3 | −9.95pp | +65.11pp | +74.18pp [+58.18, +96.24] |
| | TOTAL | −2.22pp | +12.01pp | +13.65pp [+10.44, +18.30] |

在每一条路径上，真实触发的时机都优于随机时点：同样的动作放在随机的日子几乎没有作用（清仓甚至是负的），规则的价值来自它识别出的"正在恶化"的日子。

| B 层新浪 60 分钟线（真实路径） | +5.22pp | 0（没有触发） | −0.39pp（4 个锁存日） |
| A 层确定性路径 | +0.06pp | 0 | — |
| A 层随机路径集合 | +0.66pp | 0 | +0.08pp（6 个锁存日） |
| B 层新浪 15 分钟线（较短的窗口） | +0.84pp | 0 | — |
| A 层随机路径集合（同一个 15 分钟线窗口） | −0.03pp | 0 | — |

读法：
- 生产规则对 ACC3 的效果在所有路径模型下都为正，但大小从 +13.9pp 到 +110.7pp，取决于路径：结论的方向稳健，**大小是模型条件下的**；
- 动作越激进越依赖路径：清仓在"先低后高"的路径上为 −17.2pp（在低点卖出、随后价格回升）；
- A 层的每一种路径模型都判定加仓阶梯在 11 年里大幅亏损（−67pp ~ −168pp），而在同期可比的真实分钟路径上，它是盈利的（+5.22pp，A 层模型对同一窗口只给出 +0.06pp ~ +0.66pp）。也就是说，合成路径可能**低估了逆势加仓的盈利、从而高估了拦下加仓的价值**；B 窗口行情平稳，这一对照不能推广到剧烈行情，但足以说明 §4.2 的数字不能当作真实效果的估计。

### 4.6 B 层：真实分钟路径（`minute`）

用新浪 60 分钟线展开的真实日内路径，在 10 个品种的共同区间（2026-01-13 ~ 2026-09-24，171 个交易日）上做同样的配对实验：

- 3% 阈值下**没有任何级别触发**（ACC3 连 −2% 的告警都没有），所有方案的结果与基线完全相同，差值全部为 0；
- 在真实分钟路径上，ACC3 的加仓阶梯是**盈利**的：ACC3 总收益 +1.94%，去掉加仓的 ACC3B 为 −3.28%，加仓贡献 +5.22 个百分点。

这段时间行情平稳，B 层不能说明规则在剧烈行情中的效果，但它给出了一个重要的对照：A 层合成路径上"加仓阶梯大幅亏损、所以拦住加仓很有价值"的结论，在真实路径上并不成立（§4.4）。

### 4.7 触发的质量：真阳 / 假阳、界定分类、换月

以下统计取自基线（仅告警）方案，即规则只记录、不干预时的触发，20 条路径的中位数。

**熔断级别（−3%）的触发**：17,112 个账户日（6 个账户 × 2852 天）中触发 318.5 次，扣除 9.5 次换月日后 310.5 次。"真阳"指从触发当日的日初算起，到某一时点的累计亏损仍不小于 3%：

| 计价口径 | 当日 | 次日 | 5 日后 |
|---|---:|---:|---:|
| 收盘价（主口径） | 64.4% | 54.3% | 51.9% |
| 次日开盘价 | 63.2% | 54.9% | 51.7% |
| 结算价 | 21.3% | 55.3% | 52.2% |

约三分之二的熔断触发到当日收盘时亏损仍在 3% 以上，约一半持续到次日及以后。当日的结算价口径只有 21.3%，是因为结算价是全天成交量加权平均价，下跌日它高于收盘价，会把当日的亏损"抹掉"一部分，不能用来判断触发的对错。开盘跳空直接触发的占 9.7%；合成路径在夜盘与日盘之间没有跳空，这是下限。

**界定分类**：只用日线就能确定的部分。对开盘后的持仓，任何与日线一致的路径都会触发的记为"必然"，任何路径都不会触发的记为"不可能"，其余为"不确定"：

| 级别 | 必然 | 不确定 | 不可能 | 真实触发次数的区间 | 随机路径实际触发 |
|---|---:|---:|---:|---|---:|
| 告警 −2% | 483 | 373 | 16,256 | [483, 856] | 770.5 |
| 限制 −2.5% | 301 | 210 | 16,601 | [301, 511] | 482.5 |
| 熔断 −3% | 185 | 153 | 16,774 | [185, 338] | 318.5 |

随机路径的触发次数都落在区间内、靠近上端；其中熔断有 31 次是策略自己在盘中的交易（主要是 ACC3 的加仓）造成的，这部分不能由开盘持仓推出。

**换月**：797 个持仓换月的账户日。若用未经调整的连续合约序列，会多出 25 次假熔断、漏掉 0 次；回测持有真实合约并按换月比例调整信号序列（§3），所以没有这类假触发。

### 4.8 阈值扫描（`sweep`）

熔断阈值 T 取 0.75%、1%、1.5%、2%、2.5%、3%、4%、5% 共 8 档（整条阶梯随 T 缩放），与 5 个动作档位交叉；样本内 2015-01-05 ~ 2020-12-31，样本外 2021-01-04 ~ 2026-09-24；每格 3 条随机路径，取中位数。同期基线：样本内合计 +28.27%（最大回撤 7.49%），样本外合计 −2.61%（最大回撤 15.29%）。

生产规则（限制+熔断）相对同期基线的总收益差值（百分点）：

| 阈值 | 0.75% | 1% | 1.5% | 2% | 2.5% | **3%** | 4% | 5% |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 样本内 TOTAL | +7.36 | **+7.64** | +6.44 | +4.88 | +3.78 | +3.00 | +1.81 | +0.73 |
| 样本内 ACC3 | +40.68 | +41.98 | +32.96 | +24.91 | +20.79 | +16.50 | +9.97 | +3.99 |
| 样本内 ACC3B | −2.73 | +1.03 | +0.52 | +0.88 | +0.36 | +0.30 | +0.12 | +0.02 |
| 样本内 锁存的账户日 | 1128 | 792 | 447 | 275 | 179 | 125 | 60 | 26 |
| 样本外 TOTAL | **+7.57** | +6.74 | +6.15 | +4.71 | +3.87 | +3.04 | +1.91 | +1.18 |
| 样本外 ACC3 | +39.54 | +36.82 | +33.30 | +25.92 | +21.26 | +16.72 | +10.53 | +6.46 |
| 样本外 ACC3B | −2.98 | −2.13 | −1.43 | −0.52 | −0.19 | −0.12 | −0.04 | 0.00 |
| 样本外 锁存的账户日 | 914 | 625 | 338 | 196 | 118 | 83 | 41 | 20 |

读法：
- 在这个模型下，**阈值越紧效果越大**：合计收益的最优阈值在样本内为 1%，在样本外落在网格边缘 0.75%；样本内外的排序高度一致（合计收益的 Spearman 秩相关 0.98）。减半、清仓两档大体也是这个形状（最优在 0.75%~1%，放宽到 4%~5% 时效果接近 0）；
- **3% 处是一段斜坡，不是平台**：报告对 3% 附近是否平坦、是否接近最优做了检验，对合计和 ACC3 都不通过。所以不能说"3% 落在稳健的平台区"；
- 收紧阈值的额外收益几乎全部来自更早拦住 ACC3 的加仓：对不加仓的 ACC3B，最紧的阈值反而为负（样本外 −2.98pp），STATIC 基本为 0；
- 代价是触发频率：样本内 0.75% 阈值下锁存 1128 个账户日，是 3% 的 9 倍，相当于账户经常处在熔断中，规则就不再是"极端情况下的刹车"。

## 5. 结论与局限

**结论**（除第 1 条外，都以 A 层的日内路径模型为条件）：
1. **机制正确**：验收场景在生产的风控内核上被精确复现（D 层 16/16）：−2% 告警、−2.5% 限制、−3% 立即禁开并在第二个行情状态锁存、开仓被拒而平仓成交、单个坏点不会锁存。端到端验收（06 §6）在 8 个真实进程上得到同样的行为。
2. **生产规则的收益来自拦住逆势加仓**：限制+熔断让合计收益 +6.28pp、最大回撤 −2.21pp（统计显著），其中 99% 来自 ACC3 被拦下的加仓；对不在日内加仓的持仓（STATIC、ACC3B）几乎没有作用。这符合规则的性质：禁开只阻止新增风险，不减少已有持仓。
3. **触发的时机有价值**：同样的动作放到随机日子几乎没有效果（安慰剂），按收盘价约 64% 的熔断触发到当日收盘时亏损仍在 3% 以上、约一半持续到次日之后。触发次数落在只用日线就能确定的区间内。
4. **更激进的动作收益更大，但更依赖路径**：熔断后减半、清仓在主要结果中效果更大，对不加仓的账户也有效；但清仓在"先低后高"的路径上变为负值，在开盘即跳空的日子（2020-02-03）也无能为力。这支持现在的设计：自动执行的只有禁开，减仓计划由风控经理确认后执行（04 §7.5，TD-08）。
5. **效果的大小不可当真**：ACC3 的效果随路径模型在 +14pp ~ +111pp 之间；A 层的所有路径模型都判定逆势加仓大幅亏损，而同期可比的真实分钟路径上它是盈利的。合成路径很可能高估了拦下加仓的价值，真实效果需要用 C 层（自录 tick）和更长的分钟线历史检验。
6. **3% 是题目给定的验收阈值，不是回测优化出来的**：04 §4.3.1 按 CTA 账户的日波动把它放在约 3~5 个日 σ 的位置。阈值扫描在这个模型下呈单调斜坡（越紧越好，最优在 0.75%~1%），3% 不在平台区；但更紧的阈值的收益同样来自拦住逆势加仓，受第 5 条所说的路径偏差影响，而且触发次数成倍增加。回测支持"熔断禁开有效"的方向，不支持把阈值精确到某个数值。

**局限**（报告第 14 节有完整清单）：
- A 层的日内路径是合成的：路径模型只用最近几个月的新浪分钟线校准，再外推到 2015 年以来；没有夜盘与日盘之间的跳空；
- 历史合约一律按 2026 年的乘数、手续费、保证金和交易时段计算；成交没有滑点和部分成交；封板用启发式判断；
- DCE 约 7% 的交易日结算价为估算值，DCE 的换月比例也用估算值；
- 策略是 strategy-sim 机器人在 K 线上的近似实现，不是机器人本身；仓位按初始资金定规模、不复利；
- 只启用了日亏规则，其他规则（回撤、集中度、杠杆等）与它的相互作用没有度量；
- C 层（真实 tick）的回放要等 2026-09-28 起的录制完成。

## 6. 如何复现

```powershell
futrisk backtest run breaker_synthetic       # D 层验收剧本，几秒，结束时打印 "scenario checks: 16/16 passed"
futrisk backtest run default                 # 主要结果
futrisk backtest run stress                  # 压力窗口
futrisk backtest run sweep                   # 阈值 × 动作扫描
futrisk backtest run minute                  # B 层分钟线
futrisk backtest run default --set ensemble.paths=4 --set start=20200101 --workers 8   # 缩短的试跑
```

| 配置 | 内容 | 工作进程 | 用时 |
|---|---|---:|---:|
| `breaker_synthetic` | D 层验收剧本 | 12 | 5s |

| `stress` | 9 个压力窗口 × 20 条路径 | 12 | 5.4 分钟 |
| `default` | 2852 个交易日 × 20 条路径 × 8 个方案，外加 12 组敏感性变体；共回放 381 万个账户日、5.25 亿个 tick | 15 | 2.1 小时 |
| `sweep` | 8 档阈值 × 5 个档位 × 样本内 / 样本外 × 3 条路径；共回放 2.71 亿个 tick | 15 | 62 分钟 |
